# Social Media Links Configuration

## Current Social Media Links

The footer includes social media links for:

1. **Instagram** - `https://instagram.com/digitos`

3. **LinkedIn** - `https://linkedin.com/company/digitos`

## How to Update Links

To update the social media links, edit the `Footer.tsx` file and replace the URLs in these locations:

### In the "Stay Connected" section (lines 65, 75, 85):
```tsx
href="https://instagram.com/digitos"  // Replace with your Instagram URL
href="https://twitter.com/digitos"    // Replace with your Twitter URL
href="https://linkedin.com/company/digitos"  // Replace with your LinkedIn URL
```

### In the bottom social media section (lines 102, 112, 122):
```tsx
href="https://instagram.com/digitos"  // Replace with your Instagram URL
href="https://twitter.com/digitos"    // Replace with your Twitter URL
href="https://linkedin.com/company/digitos"  // Replace with your LinkedIn URL
```
